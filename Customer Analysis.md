# &#x20;                      **Customer Analysis Dashboard**



**Project Overview**

The Customer Analysis Dashboard project was developed to analyze customer demographics, spending behavior, and income patterns using Python, MySQL, and Power BI. The project focuses on generating business insights through data cleaning, SQL analysis, and interactive dashboard visualizations to support customer segmentation and business decision-making.



**Objectives**

\- Analyze customer demographics and spending behavior

\- Identify high-value customers

\- Study income and spending trends

\- Perform customer segmentation analysis

\- Build an interactive business dashboard



**Tools \& Technologies Used -** Python, Pandas, NumPy, MySql, Power BI, DAX



**Dataset Information**

The dataset contains customer-related information such as Customer ID, Gender, Age, Annual Income, Spending Score



**Project Workflow**



**1. Data Cleaning using Python Performed**:

\- Null value handling

\- Duplicate removal

\- Data type verification

\- Customer data preprocessing

\- Exploratory data analysis



**2. SQL Analysis using MySQL Executed SQL queries for:**

\- Customer count analysis

\- Gender-wise customer analysis

\- Purchase amount analysis

\- Category-wise sales analysis

\- Customer spending analysis

\- Previous purchase analysis

\- Product and shipping analysis

\- Sales filtering, grouping, and sorting

**3. Dashboard Development using Power BI Created:**

\- KPI Cards

\- Interactive charts

\- Customer segmentation visuals

\- Dynamic slicers and filters

\- Business insights dashboard



**KPI Metrics**

\- Total Customers

\- Average Annual Income

\- Average Spending Score

\- High-Value Customers



**Dashboard Visualizations**

\- Gender Distribution Analysis

\- Age Group Analysis

\- Spending Score Analysis

\- Income vs Spending Scatter Plot

\- High-Value Customer Analysis

\- Customer Segmentation Dashboard



**Key Insights**

\- Young adult customers showed higher spending behavior.

\- High-income customers contributed significantly to revenue.

\- Customer segmentation helped identify premium customers.

\- Spending behavior varied across age groups and income levels.



**Features**

\- Interactive Power BI dashboard

\- Dynamic filtering using slicers

\- Business-focused customer analytics

\- End-to-end analytics workflow

\- SQL and DAX calculations
